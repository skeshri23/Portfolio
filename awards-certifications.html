Awards and Certifications

Iris Detection System

HackOHI/O Hackathon
September 2024

Developed a real-time iris detection and authentication system using Python, OpenCV, and MediaPipe for secure keyless car unlocking. The system involved facial feature extraction, precise identification of iris landmarks, and depth analysis to ensure accurate biometric authentication. Designed a visual feedback mechanism to simulate real-time authentication success or failure. Optimized the system for smooth processing of live video feeds, ensuring high frame rates and efficient resource usage for continuous detection, which garnered attention for its real-time performance and application in enhancing security.

Course Kata Data Analysis

Judges’ Choice, ASA Data Fest
April 2024

Led a team in conducting an in-depth analysis of Course Kata’s textbook engagement datasets to uncover key user engagement patterns and address learning challenges. Using statistical and analytical techniques with R and Microsoft Excel, we generated actionable insights aimed at improving student learning experiences. We presented data visualizations to clearly communicate our findings and provided recommendations for enhancing engagement. Our innovative approach to educational data analysis earned the Judges’ Choice award, showcasing our ability to leverage data for impactful improvements in education.

Park Assist

Medalist Project, 10th Make OHI/O Hackathon
March 2024

Designed and implemented an innovative solution to improve urban parking efficiency using ultrasonic sensors and AI algorithms. Programmed a user-friendly interface with Java and Arduino to enable real-time detection of cars and identification of vacant parking spots. The project aimed to reduce parking time and driver frustration while contributing to sustainability by lowering emissions, ultimately enhancing urban mobility in crowded cities. The project was recognized with a medal for its innovative approach to solving urban parking challenges.

# Personal Portfolio Website

This repository contains the source code for my personal portfolio website, built to showcase my
education, technical skills, projects, work experience, and achievements as a Computer Science graduate.

The site serves as a central place for recruiters and collaborators to learn about my background
and view selected software engineering and machine learning projects.

---

## Live Website
https://skeshri23.github.io/Portfolio/

---

## Features
- Clean, responsive multi-page layout
- Dedicated sections for:
  - Projects
  - Work experience
  - Technical skills
  - Awards & certifications
- Simple, readable UI focused on clarity and accessibility
- Custom styling without heavy frameworks

---

## Technologies Used
- HTML5
- CSS3
- JavaScript

---

## Project Structure
- `index.html` – Home page
- `projects.html` – Project highlights
- `work-experience.html` – Professional experience
- `technical.html` – Technical skills
- `awards-certifications.html` – Awards and recognitions
- `style.css` – Global styling
- `script.js` – Client-side interactions
- `images/` – Website assets

---

## Purpose
This website was designed and implemented from scratch to:
- Present my profile in a professional, recruiter-friendly format
- Demonstrate frontend fundamentals
- Complement my resume and GitHub project repositories

---

## Notes
- The site is continuously updated as I add new projects and experiences
- Major projects linked on the site are maintained in separate GitHub repositories
